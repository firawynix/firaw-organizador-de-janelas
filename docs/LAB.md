# Publicação de demonstração no lab

O site está em `site/dist` e usa caminhos relativos para funcionar em
`https://lab.firawynix.com.br/foj/`.

Antes de publicar, confira o pacote com `lab-remoto previa` e envie a pasta
`site/dist` como site estático público com o nome `foj`, conforme
`G:\firawos\workspace\lab-sandbox\LAB-AGENTES.md`.

O executável público é distribuído pelo GitHub Releases. O site no lab não
carrega a cópia local em `site/dist/downloads`, que é ignorada pelo Git e
deve ser removida da pasta enviada ao lab.

O ícone do menu Produtos é `assets/foj-product-menu.png`: PNG branco,
128 × 128, transparente e monocromático, derivado do nó celta da marca.
Seu desenho editável está em `assets/foj-product-menu.svg`.
